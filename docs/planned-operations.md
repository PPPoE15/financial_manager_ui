# FM-109: список запланированных операций

Задача: https://github.com/PPPoE15/fm-auto-dev/issues/109, история #104.
Контракт: `fm-auto-dev/contracts/planned-operations.md`, FM-106.

## Реализация

Защищённый `/planned-operations` отделён от фактических операций. API читает все страницы
по `next_skip`, объединяет UID и сохраняет порядок даты/UID. Сегодня определяется сервером;
список обновляется при возвращении во вкладку, каждую минуту и после действий.

Поля редактируются в строке. Нижняя кнопка отправляет отдельный PATCH для каждой изменённой
строки; общей транзакции списка нет. Успешные строки выходят из черновика, ошибочные остаются.
Фоновое чтение не меняет базовую версию черновика. Конфликт показывает актуальные значения,
переход на новую версию требует явного действия. Фильтры и переходы блокируются до сохранения
или отмены правок. Сетевые сбои не повторяют мутации автоматически.

`PlanDialog` и `usePlanAction` общие для списка и будущего виджета FM-110: создание, перенос,
подтверждение, удаление, детали выполненного. Подтверждение читает фактический список и баланс;
отображаемый факт берётся из ответа сервера/GET, исходные поля плана не заменяются.
При неизвестном результате сохраняется черновик и предлагается сверка. Удалённая связь
показывается без перехода к факту. Копирование выполненного плана использует исходные значения,
включая дату; прошедшая дата требует исправления.

## Проверка

`npm test`, `npx eslint .`, `npm run build`, Python-тесты deployment client.
Новые тесты: пагинация/контракт API, ввод суммы и даты, исходные поля копии, частичное сохранение,
сверка версий, неизвестный результат, перенос/удаление, двойное нажатие, удалённый факт,
Teleport/focus/Escape, inline-редактирование и защищённый маршрут.

Локальный стенд: `npm run dev -- --host 127.0.0.1 --port 5199`,
`/dev/planning-preview.html`; параметры `?empty`, `?error`, `?unknown`.
API стенда хранит вымышленные записи в памяти и не отправляет реальные мутации.
Ручная проверка: 1440×1000, 390×844, 360×800 без горизонтального скролла;
подтверждение с изменением суммы, сохранение исходных полей, копирование, ошибка прошедшей даты,
Escape и фокус. Проверка против живого backend не выполнялась.
