# FM-94: интерфейс импорта — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Скачать шаблон и импортировать расходы/доходы в CSV/XLSX с понятным результатом и обновлением экрана.
**Architecture:** API через общий http; composable управляет выбором файла, загрузкой и ошибками; диалог использует BaseButton/ErrorMessage и текущую тему. HomeView обновляет существующие карточки по saved.
**Tech Stack:** Vue 3, TypeScript, Tailwind, Vitest.
**Spec:** PPPoE15/fm-auto-dev#94; contracts/import-export.md на origin/master fm-auto-dev; Figma 888:798.

## Global Constraints
- Отдельный worktree, ветка codex/fm-94-import от origin/dev.
- Русские docstring и UI; пользователь разрешил адаптацию состояний и узкого экрана.
- Только CSV/XLSX, файл ≤5 242 880 байт; один тип на файл.
- После неизвестного исхода нет автоматического повтора; явно предложить проверить операции.
- Макет 800×672, масштаб текущей темы 0.75; существующие токены вместо новых цветов.

## Review Focus
- Смена типа не должна отправлять ранее выбранный файл другого типа.
- Неизвестный исход не означает rollback; заблокировать немедленный повтор выбранного файла.
- CSV адресует логические записи, XLSX — строки листа.
- Ошибка скачивания Blob не должна отображаться как успех.
- Не допускаются повторная отправка и потеря фокуса при блокировке контролов.
