# Импорт операций — FM-94

Источник макета: [Figma, окно 888:798](https://www.figma.com/design/FAPPJ3LrAUEY8indrAbfnV/Fin-Manager?node-id=888-798), раздел «Новый дизайн», просмотрено в Chrome 27.10.2026.
Исходный размер 800×672, заголовок Inter Bold 32px, отступ слева 48px; используется масштаб текущей темы 0.75 и её существующие цвета. Кнопка «Импорт CSV» в меню открывает окно для CSV **и** Excel.
Пользователь согласовал узкую версию, выбранный файл, загрузку, успех и ошибки в текущем стиле. Предупреждения о лимитах и повторном импорте добавлены по контракту.

## Поведение

- GET `/import-export/templates/{income|outcome}?format=csv|xlsx`: Blob и фиксированное имя `{type}-template.{format}`.
- POST `/import-export/imports/{income|outcome}?format=csv|xlsx`: один файл в FormData; заголовок multipart выставляет браузер.
- Смена типа сбрасывает файл. Размер проверяется до отправки: 1–5 242 880 байт; поддерживаются `.csv` и `.xlsx` без учёта регистра.
- В процессе импорта заблокированы смена типа, выбор файла, отправка и закрытие. Сохранение атомарно на backend.
- Ошибки отображаются по `code`, адресам `row/field` и русским сообщениям контракта. CSV — физическая строка начала записи (FM-96), Excel — строка листа; `errors_truncated` показывается отдельно.
- Сеть, тайм-аут, неизвестный ответ и FM-503301 не подтверждают rollback: предложить проверить список операций, очистить выбранный файл, не повторять POST автоматически. FM-500301 подтверждает отсутствие сохранения.
- Успех очищает файл, показывает число операций и вызывает существующий `onTransactionsSaved`: обе карточки операций, структура бюджета, финансовый график. Никакой перезагрузки страницы.
- Диалог удерживает фокус и блокирует фон через inert; при закрытии возвращает фокус на пункт меню.

## Production-прокси

Для `/transaction/import-export/imports/{income|outcome}` nginx разрешает multipart-тело
до 6 МиБ включительно (файл до 5 МиБ проверяют UI и backend). Превышение возвращает
`application/problem+json`, HTTP 413 и `FM-413301`; POST не повторяется на другом upstream.
Лимиты остальных маршрутов не меняются.

Регрессионная проверка: `python3 scripts/test-import-proxy.py` (Docker, OpenSSL).
Она запускает nginx 1.29.2 с production-конфигурацией и временным upstream, проверяет
2/6 МиБ, превышение 6 МиБ, оба типа операций, Content-Length/chunked, JSON-ошибку,
сохранение URI и прежний лимит другого маршрута. Контейнер удаляется после проверки.

## FM-96: упрощённый CSV (29.10.2026)

Тексты существующего окна обновлены по требованиям FM-96. Макет 888:798 повторно
просмотрен в Figma через Chrome; структура DOM, классы и визуальные компоненты сохранены.
Правила CSV показываются по умолчанию и при выборе CSV; выбор Excel показывает отдельные
подсказки с прежним порядком колонок и четырёхзначным годом. CSV поддерживает обязательные
заголовки в любом порядке, дополнительные колонки, запятую/точку с запятой, годы yy/yyyy,
произвольные нецифровые разделители даты, день и месяц из одной или двух цифр и очистку краёв всех значений.
Пробелы, точки и запятые между цифрами суммы считаются разделителями разрядов: `1,25` — 125 рублей,
не дробное число. Название неизвестной категории показывается в ошибке, полученной от API.
Парсинг остаётся на сервере; для разделителя CSV внутри суммы необходимы кавычки.

В ошибках CSV отображается «Строка файла N · Поле», номер берётся из ответа без пересчёта.
Для row=null сохраняется «Файл». FM-422301 с reason=invalid_encoding предлагает UTF-8;
при ошибке структуры кодировка не упоминается. Пустой CSV диагностируется на клиенте
с адресом строки 1. Сохраняются причины сервера, усечение списка и защита от повторного
импорта после неизвестного результата. Нормативный контракт в fm-auto-dev остаётся отдельной частью FM-96.

Проверки frontend FM-96: исходные 432 теста прошли; новые сценарии прошли RED→GREEN.
Итог: 444 теста, ESLint и TypeScript/Vite build проходят. В Chrome проверено отдельное
окно компонента на ширинах 360 и 800 px: переносы подсказок, отсутствие обрезанного текста,
доступность кнопок и вертикальной прокрутки. Выбор формата и ответы API проверены
компонентными тестами с заглушкой транспорта. Новый сквозной импорт через настоящий
backend в этом запуске не выполнялся. Временная страница визуальной проверки удалена.
