# Планирование операций на главной — FM-110

Главная показывает первые четыре невыполненных плана в серверном порядке
(дата, UID), включая будущие. Запрос: `GET /planned-operations?include_completed=false&limit=4&skip=0`.
Заголовок ведёт в отдельный список. Подсветка «Сегодня» / «Просрочено» использует
`today` ответа, а не календарь браузера. Перечитывание — при входе, возвращении
во вкладку, раз в минуту и после действия. Устаревший запрос отменяется и не
может заменить новый результат. Ошибка загрузки не выдаётся за пустой список.

Подтверждение и перенос используют `PlanDialog` из FM-109: версии, сверка после
конфликта/неизвестного результата, отсутствие автоматического повтора мутаций.
После действия обновляются блок и фактические карточки/отчёты. Выполненный план
позволяет создать новый из исходных значений, удалить план или открыть связанный
факт в существующем редакторе. Изменение категорий обновляет также ближайшие планы.

не подписывает тип доход/расход и не содержит кнопки «Все планы».
Загрузка, ошибка с «Повторить», полное отсутствие планов оформлены по образцу
существующих карточек главной — согласовано пользователем 10.11.2026.

На узком экране блок стоит первым после приветствия; на широком — под категориями.

## Проверка

Автотесты проверяют ограниченный запрос, будущие даты, смену серверного дня,
защиту от запоздавшего ответа, загрузку/ошибку/повтор/пустоту, переход в список,
общие диалоги, перенос и обновление фактических карточек.

Ручной сквозной прогон 10.11.2026: Vite FM-110 + реальный локальный Docker API
FM-107/108 и PostgreSQL, отдельный тестовый пользователь FM-110:

- пустой блок → заголовок → список → создание плана на сегодня;
- отрицательный ввод суммы отклонён, дата вчера отклонена;
- inline-изменение 1200 → 1300, сохранение из списка;
- перенос с главной на 12.11: план остаётся ближайшим, подсветка снята;
- подтверждение с суммой 900, датой 10.11, другой категорией и комментарием;
- исходные 1300 / 12.11 / ЖКХ / комментарий сохранены; новый факт отличается;
- «Запланировать еще» предзаполняет исходные значения;
- выполненный скрыт с главной и из списка по умолчанию, доступен по галочке;
- удаление выполненного плана сохраняет факт 900: проверено UI и GET API;
- создание дохода 25000, фильтр расходов не показывает его, подтверждение
  дохода на мобильном экране, переход к связанному факту;
- пять активных записей: API и виджет показывают четыре ближайшие;
- сверка desktop 1920×1080, mobile 360×800: горизонтальной прокрутки нет.

Сетевые ошибки и смена серверного дня проверены детерминированными автотестами,
без изменения часов или остановки общего локального стенда.
